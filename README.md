# KICKWEB.DE – GitHub Pages

Retro-1998-FIFA-inspirierte Website für KICKWEB.DE.

## Formular
Das Kontaktformular nutzt den offiziellen FormSubmit-AJAX-Endpunkt für statische GitHub-Pages-Websites. Die Anfrage wird an `kickweb.de@gmail.com` gesendet, ohne die Website zu verlassen. FormSubmit muss die Empfängeradresse beim ersten Einsatz eventuell einmalig per Bestätigungs-Mail aktivieren.

## Dateien
- `index.html` – Startseite
- `fc-talblick.html` – Demo-Verein
- `style.css` – Styles
- `script.js` – Navigation + Formularversand
- `impressum.html` – Impressum-Platzhalter
- `datenschutz.html` – Datenschutz-Platzhalter
- `assets/` – Logo und Favicon
